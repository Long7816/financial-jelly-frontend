# 投資人使用體驗審核

日期：2026-09-23。審核身分：希望快速掌握營運、獲利、現金流、財務結構與證據的一般投資人。

## 實際操作範圍

- 研究入口：有效搜尋、無結果、未開放公司、最近研究、自選增刪。
- 公司探索：搜尋、產業與財務面向篩選、排序、自選與進入研究。
- 我的自選：收藏、移除、空狀態及重新整理保存。
- 市場與產業：大盤、產業表現、資料覆蓋三個頁籤。
- 財報／法說行事曆：清單、月曆、事件類型、只看自選及公司連結。
- 公司研究：總覽、股價與技術、營運與獲利、現金流、財務安全、風險與證據、估值與同業、籌碼與法人。
- AI 財報助理：三個建議問題、自由輸入、送出、固定示範回答與按需查看的細節。
- 桌機與 390px 手機：導覽、頁籤、圖表、數值帶、收合內容及水平溢位。

## 暫時不應假裝已解決

1. 財務、行情、同業、法人與行事曆仍是固定 Mock；沒有正式資料來源時，不能當成投資研究結果。
2. 只有聯電具有示意研究頁；其他公司可收藏但尚無分析內容。
3. AI 只有一題固定示範計算，不是已串接 Agent。原始財報文件、頁碼、Note-RAG 與 Guardian 尚未執行。
4. 自選只保存在本機瀏覽器，沒有帳號、跨裝置同步、自訂欄位或通知。
5. 技術圖表尚無時間區間、游標提示、復權設定與正式行情來源；在核心財報 Demo 穩定前不擴張為完整看盤產品。
6. 同業 A／B 與產業中位數只是欄位示意；正式比較必須取得可公開使用的同期間資料與明確公司名稱。
